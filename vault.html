Vault — Encrypted Identity Storage

This is the planned storage layer for Solivre: encrypted identities, attributes and commitments anchored to your local node. Phase 1 focuses on Agent + Verifier, so the Vault UI is marked as work in progress.

Status: WIP

The backend already stores identities and attributes in an in-memory Vault. This page will grow into a full dashboard to inspect, back up and manage those records.

  • List identities stored in the local node.
  • Inspect commitments and attribute roots without exposing raw attributes.
  • Export/import encrypted snapshots for backup and migration.
  • Future: plug different storage backends (filesystem, DB, hardware modules).
